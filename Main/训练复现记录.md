# DeepOFW 复现训练记录

## 1. 论文概述

**论文标题**：DeepOFW: Deep Learning-Driven OFDM-Flexible Waveform Modulation for Peak-to-Average Power Ratio Reduction

**核心思想**：用一个GRU-based神经网络根据信道冲激响应（CIR）生成波形矩阵Q和检测器参数q，使得：
- 低delay spread信道 → 波形趋向TDM（时分复用），PAPR极低
- 高delay spread信道 → 波形趋向OFDM（频分复用），保证BER性能

**模型架构**：
- 输入：时域信道冲激响应 `pilots_post_channel`
- 网络：Complex Conv1D → Complex GRU (1024 units) → Dense → 输出 Q (N×N) 和 q (N)
- 辅助网络：Uncertainty Model（自适应loss权重）、PAPR阈值网络

**损失函数**：
```
L = exp(-σ_R) * BCE + exp(-σ_P) * PAR + exp(-σ_Θ) * ε + σ_R + σ_P + σ_Θ
```

## 3. 训练过程分析

### 3.1 训练是分步的

通过阅读代码和论文Section V-A，确定训练分**两个阶段**：

| 阶段 | 脚本 | 学习率 | SNR范围 | Batch Size | 说明 |
|------|------|--------|---------|------------|------|
| Stage 1 | `train_GraphMode.py` | 0.001 | [10, 25] dB | 2560 | 从零训练，保存为`weights-qQ_Method_initial` |
| Stage 2 | `train.py` | 0.0001 | [20, 25] dB | 2560 | 加载Stage 1权重fine-tune，保存为`weights-qQ_Method` |

论文原文（Section V-A）：
> "A second training stage is applied for fine tuning using shorter blocks consisting of a single time-domain symbol (32 QAM symbols), a batch size of 14,000, a learning rate of 0.0001, and higher SNR values ranging from 20dB to 25dB."

## 4. 实际训练过程

### 4.1 Stage 1：从零训练

**脚本**：`train_stage1.py`

**关键参数**：
- Learning Rate: 0.001
- Batch Size: 2560 (BATCH_SIZE=10, ×256)
- SNR: 随机采样自 [10, 25] dB
- 信道模型: TDL-A with random delay spread [10ns, 600ns]
- 优化器: Adam
- 使用`@tf.function`加速

**监控策略**：每100步在20dB SNR下评估BER，保存最优权重。

## 5. 评估结果

### 5.1 BER性能

最终模型在不同SNR下的BER：

| SNR (dB) | BER |
|-----------|------|
| 10 | ~0.16 |
| 15 | ~0.10 |
| 20 | ~0.043 |
| 25 | ~0.03 |

### 5.2 CCDF对比（PAPR性能）

运行CCDF评估脚本，生成`ccdf_comparison.png`：
- OFDM：PAPR约6dB @ CCDF=10^-2
- DeepOFW低delay spread（蓝色）：PAPR约3-4dB，显著优于OFDM
- DeepOFW高delay spread（红色）：PAPR约5dB，仍优于OFDM

### 5.3 波形特性验证

运行`qQ_waveforms_inspec_scan.py`，在10ns-620ns范围内每10ns一步生成波形可视化：

**低delay spread (10ns)**：
- 时域：波形为集中的脉冲，分布在不同时间位置 → **类似TDM**
- 频域：宽带，能量平铺在整个频带

**高delay spread (580ns)**：
- 时域：波形为周期性正弦，分布在整个时间段 → **类似OFDM**
- 频域：窄带峰值在不同频率位置，类似子载波

这与论文Figure 7-11完全一致，验证了DeepOFW的核心机制：根据信道条件自适应调整时频域的能量分布。

## 7. 复现要点与教训

1. **训练不稳定性**：Uncertainty Network会导致模型collapse（PAPR权重过大，忽略BER）。需要基于eval BER做early stopping，而非只看loss。

2. **两步训练的必要性**：Stage 1先学会基本通信能力，Stage 2在高SNR下精细调整。直接从零用高SNR训练会导致模型陷入局部最优。

3. **充分训练的重要性**：原作者可能训练了数万步。我们的Stage 3用了10000步（加上之前共约13000步），BER从0.5降到0.043，但仍未完全达到论文水平（~0.01-0.02 @ 20dB）。继续训练可进一步提升。

4. **`@tf.function`加速**：使用graph mode比eager mode快约3-5倍，对长时间训练至关重要。

5. **GPU利用**：TF 2.15默认使用单GPU。训练时batch size 2560在V100上约占8GB显存。

## 8. 如何继续训练

如果需要进一步降低BER，可以：

```bash
source activate deepofw
# 设置LD_LIBRARY_PATH（见上文）
python train_stage3.py  # 会自动加载当前最优权重继续训练
```

或修改`train_stage3.py`中的参数：
- 降低`LEARNING_RATE`到0.0001
- 增加`NUM_ITERS`到50000
- 调整SNR范围
