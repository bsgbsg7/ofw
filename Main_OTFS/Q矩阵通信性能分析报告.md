## 1. 实验设计

### 核心问题

模型学到的 Q 到底是什么？它在高速时变信道下如何提升通信性能？

### 方法：消融实验

在同一信道条件下对比三种 Q 矩阵的 BER：

| Q 类型 | 说明 | 对应方案 |
|:---|:---|:---|
| **Learned Q** | 模型从 CIR 自适应生成的 Q | DeepOFW 学习到的波形 |
| **Fixed IDFT** | 标准 IDFT 矩阵 $F_{kn} = e^{j2\pi kn/N} / \sqrt{N}$ | 标准 OFDM |
| **Fixed Identity** | 归一化单位阵 $I / \sqrt{N}$ | 单载波 / TDM |

### 测试条件

- **速度范围**: 3 ~ 200 m/s (≈ 10 ~ 720 km/h)
- **延迟扩展范围**: 10 ns ~ 500 ns (平坦 ~ 丰富多径)
- **SNR**: 15 dB
- **信道模型**: 3GPP TDL-A, 时变

### 3.2 关键发现

#### Q 的"秘密"：非 IDFT 的部分扩展策略

```
          TDM (I)              Learned Q            OFDM (IDFT)
          ↓                    ↓                     ↓
  能量集中单点         能量部分扩展 5-8 点      能量均匀扩展 9.2 点
  dist_I = 0         dist ∈ [1.7, 1.9]        dist_IDFT = 0
  BER 多径 = 0.40    BER 多径 = 0.03-0.13     BER 多径 = 0.12-0.28
```

**本质**: Learned Q 在"符号能量集中度"上做了一个折中：
- **不完全集中** (像 TDM) → 避免多径导致的深度衰落
- **不完全均匀** (像 OFDM) → 避免过多的能量扩散和正交性损失
- **自适应调整** → 根据 CIR 的多径程度决定扩展宽度

#### 主要自适应维度：延迟扩展，非 Doppler

```
Q 随延迟扩展变化:  🔴 显著 (dist_IDFT 在平坦 vs 多径间差异大)
Q 随速度变化:      🟡 较弱 (dist_IDFT 保持 1.7-1.8 范围不变)
```

Learned Q 是一个**多径自适应的时频变换**，而非传统意义上的 OTFS (DD 域映射)。

## 4. 多普勒免疫机制

| Speed | Learned Q ICI 泄漏 | IDFT ICI 泄漏 | Learned Q PAPR | IDFT PAPR |
|:---|:---|:---|:---|:---|
| 3 m/s | 0.049 | 0.000 | 6.8 dB | 5.5 dB |
| 30 m/s | 0.045 | 0.000 | 5.3 dB | 8.5 dB |
| 60 m/s | 0.051 | 0.000 | 7.8 dB | 8.7 dB |
| 120 m/s | 0.049 | 0.000 | 5.3 dB | 6.6 dB |
| 200 m/s | 0.053 | 0.000 | 5.6 dB | 6.2 dB |

**观察**:
- Learned Q 的 ICI 泄漏 (~0.05) 来自 Q 本身非酉性，与信道速度无关
- IDFT 是完美酉矩阵 (ICI=0)，但在实际多径信道中 BER 更差
- PAPR: Learned Q 和 IDFT 接近 (5-9 dB)，无明显优劣

**为什么非酉 Q 反而 BER 更好？**  
因为 IDFT 的正交性在**时变多径信道下被破坏**。信道的时变特性使得完美的频率正交不再保持，而 Learned Q 通过牺牲一部分理想正交性，换来了对信道失配的鲁棒性。

## 5. 综合结论

### 模型学到了什么？

| 能力 | 状态 | 证据 |
|:---|:---|:---|
| 平坦信道 → TDM | ✅ 完美 | dist_I ≈ 1.02, BER 与 TDM 一致 |
| 多径信道 → 优于 OFDM 的自适应变换 | ✅ 出色 | BER 比 OFDM 好 2×–5× |
| Doppler 自适应 | 🟡 部分 | 高速下增益缩小但保持 >1.0 |
| DD 域集中映射 (OTFS) | ❌ 未实现 | Q 变化主因是延迟扩展而非 Doppler |

### 一句话总结

**模型学到的不是传统 OTFS，而是一种数据驱动的、多径自适应的时频变换，它在所有多径条件下都显著优于 OFDM (BER 提升 2–5 倍)，且能自动在平坦信道下退化为 TDM。**

### 与 OTFS 的关系

| 维度 | 传统 OTFS | Learned Q |
|:---|:---|:---|
| 设计方式 | 数学推导 (ISFFT + Heisenberg) | 数据驱动 (端到端学习) |
| 操作域 | Delay-Doppler 域 | 频域→时域直接映射 |
| 对抗多普勒 | ISFFT 将时变信道对角化 | 自适应能量扩展 |
| 对抗多径 | DD 域均衡 | 部分扩展 + CIR 自适应 |
| 性能优势 | 高 Doppler 下优于 OFDM | **所有多径条件下**优于 OFDM |

### Q 矩阵的工作机制 (推测)

1. **CIR 输入** → 网络感知多径结构 (延迟 tap 的数量和能量分布)
2. **频域→时域映射** → Q 将每个子载波符号扩展到时域的部分采样点 (5-8 个，而非全部 32 个)
3. **自适应扩展宽度** → 多径越丰富，扩展越宽 (但仍不覆盖全部时域)
4. **相位扰动** → Q 在 IDFT 基础上施加 CIR 相关的相位旋转，增强对特定多径模式的匹配
