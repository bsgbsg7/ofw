## 详细训练过程

### Stage 1：从零训练

- 脚本：`train_stage1_otfs.py`
- Batch size：256
- 关键节点：
  - Iter 0: BER = 0.4821（随机猜测水平）
  - Iter 500: BER = 0.2280（开始收敛）
  - Iter 600: BER = 0.1639
  - Iter 700: BER = 0.1610（最佳）
  - Iter 800+: BER反弹到0.41，训练不稳定
  - Iter 2200: Early stopping，patience耗尽
- 输出权重：`weights-qQ_Method_TV_initial`
- 问题：训练中出现过一次loss爆炸（iter 800-1100），但early stopping保留了最佳权重

### Stage 2：高SNR微调

- 脚本：`train_stage2_otfs.py`
- 加载 `weights-qQ_Method_TV_initial`
- 使用eager模式（无@tf.function）以稳定训练
- 关键节点：
  - 初始Loss: ~4.54
  - Iter 1800: Loss = -4.9408（最佳）
  - 训练完成2000轮
- 输出权重：`weights-qQ_Method_TV`

### Stage 3：扩展训练

- 脚本：`train_stage3_otfs.py`
- 加载 Stage 2 权重，使用@tf.function加速
- 关键节点：
  - Iter 0: BER = 0.2067（加载后评估）
  - Iter 400: BER = 0.1257
  - Iter 800: BER = 0.1015
  - Iter 1200: BER = 0.0936
  - Iter 2800: BER = 0.0897
  - Iter 3400: BER = 0.08768（最佳）
  - Iter 3600-7400: 无改善，patience逐步耗尽
  - Iter 7400: Early stopping
- 输出权重：`weights-qQ_Method_TV`（覆盖Stage 2权重）

## Bug修复记录

### 问题：训练初期 NaN loss，BER恒定0.5

**根因**：CIR快照提取方式错误。原始实现使用delta脉冲通过信道来估计CIR，但提取位置在脉冲响应之后，导致全零输入。

**修复**：直接从 `h_time` 张量中提取CIR快照：
```python
# h_time shape: (batch, 1, 1, 1, 1, num_time_steps, l_tot)
for sym_idx in range(num_snapshots):
    t_idx = sym_idx * symbol_len + self._cyclic_prefix_length
    snapshot = h_time[:, 0, 0, 0, 0, t_idx, :]  # (batch, l_tot)
```

## 结果分析

- 最终BER@20dB = 0.08768，在时变信道（速度3~120 m/s）下表现合理
- 相比静态信道版本（Main/）BER更高，因为高多普勒条件增加了解调难度
- 模型成功从时变CIR中学习到了调制矩阵Q和均衡向量q
- 后续可通过波形可视化验证是否学出了OTFS-like特征
