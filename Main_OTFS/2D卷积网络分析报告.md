# 2D 卷积网络架构：OTFS 波形学习分析报告

## 1. 背景与动机

### 1.1 问题回顾

原始 `qQ_creator_conv_gru` 网络处理 CIR 输入 `(batch, l_tot=10, num_snapshots=3)` 时存在根本性问题：

- **Conv1D 沿 delay 维度**将 3 个时间快照混合为特征通道
- **GRU 沿 delay 维度**处理延迟抽头序列，而非时间演化
- **没有联合的 delay-time 二维建模**，无法学习类似 OTFS 的 delay-Doppler 域处理

### 1.2 2D 卷积的设计动机

OTFS 的核心思想是在 **delay-Doppler 二维平面**上进行信号处理：
- 发射端：ISFFT 将 QAM 符号从 time-frequency 域变换到 delay-Doppler 域
- 信道在 delay-Doppler 域呈现稀疏、近似时不变的二维卷积
- 接收端：SFFT 恢复符号

如果网络要学到 OTFS 类波形，它需要**同时理解信道在延迟维度和时间维度的结构**。2D 卷积天然适合这一任务 —— 它在 delay-time 二维平面上滑动卷积核，直接捕获 delay-Doppler 联合特征。

## 2. 架构设计

### 2.1 网络结构

新类 `qQ_creator_conv2d` 位于 `src/qQ_Method/qQ_creator_layer.py`：

```
输入: (batch, l_tot=10, num_snapshots=3) 复数 CIR
  │
  ├─ Time Positional Encoding (正弦 PE，scale=0.10)
  │
  ├─ Reshape: (batch, 10, 3, 1) 实部 + (batch, 10, 3, 1) 虚部
  │
  ├─ Complex Conv2D Block 1:  1 → 32  channels, 3×3 kernel, same padding → BN → ReLU
  ├─ Complex Conv2D Block 2: 32 → 64  channels, 3×3 kernel, same padding → BN → ReLU
  ├─ Complex Conv2D Block 3: 64 → 128 channels, 3×3 kernel, same padding → BN → ReLU
  ├─ Complex Conv2D Block 4: 128 → 256 channels, 3×3 kernel, same padding → BN → ReLU
  │
  ├─ GlobalAveragePooling2D → (batch, 256)
  │
  ├─ Complex Dense (projection): 256 → 1024 → BN → ReLU
  ├─ Complex Dense Block 1: 1024 → 1024 → BN → ReLU → Dropout(0.1)
  ├─ Complex Dense Block 2: 1024 → 1024 → BN → ReLU (+ residual from Block 1)
  │
  └─ Output Dense: 1024 → N²+N → Q matrix (N×N) + q vector (N)
```

**关键设计选择**：

| 设计点 | 选择 | 原因 |
|--------|------|------|
| 卷积核大小 | 3×3 | 覆盖 delay-time 二维邻域，在 10×3 的小输入上感受野足够 |
| 通道数扩展 | 32→64→128→256 | 逐层增加抽象能力，从低层边缘到高层语义 |
| Complex Conv2D | Wr·Xr - Wi·Xi | 保持复数信号的相位信息，与 Sionna 物理层一致 |
| 残差连接 | Dense Block 1→2 | 改善深层网络梯度流动 |
| Positional Encoding | scale=0.10 | 比之前 PE-only 版本强 2 倍，确保时间信息不被淹没 |
| 参数量 | 7,941,636 | 约 794 万参数 |

### 2.2 代码修改清单

| 文件 | 修改 |
|------|------|
| `src/qQ_Method/qQ_creator_layer.py` | 添加 `qQ_creator_conv2d` 类（~120 行新代码）|

## 3. 训练结果

### 3.1 训练配置

| 参数 | 值 |
|------|-----|
| 信道模型 | TDL-A，23 条多径 |
| 速度范围 | 3–120 m/s（均匀随机采样） |

### 3.2 评估 BER 收敛曲线

| 迭代轮次 | Eval BER@20dB | 变化 |
|----------|---------------|------|
| 0        | 0.4942        | 随机初始化 |
| 100      | 0.4805        | ↓ 0.014 |
| 200      | 0.4827        | ≈ 平台期 |
| 300      | 0.4604        | ↓ 0.022 |
| 400      | 0.4001        | **↓ 0.060** |
| 500      | 0.2777        | **↓ 0.122** |
| 600      | 0.1703        | **↓ 0.107** |
| 700      | 0.1256        | ↓ 0.045 |
| 800      | 0.1155        | ↓ 0.010 |
| 900      | 0.1139        | ↓ 0.002 |
| 1000     | 0.1228        | ↑ 波动 |
| **1100** | **0.1086**    | **最优** |
| 1200     | 0.1170        | ↑ |
| 1300     | 0.1274        | ↑ |
| 1400     | 0.1494        | ↑（过拟合） |

**观察**：
- **0–300 轮**：缓慢起步，网络在学习基本的 CIR 特征提取
- **400–600 轮**：快速收敛阶段，BER 从 0.40 急剧下降到 0.17
- **700–1100 轮**：精细调整阶段，BER 从 0.13 下降到 0.11
- **1100+ 轮**：开始过拟合，BER 反弹

### 3.3 与之前架构的对比

| 架构 | 最优 Eval BER@20dB | 收敛速度 | 参数量 |
|------|---------------------|----------|--------|
| 原始 Conv1D+GRU | ~0.15* (训练 BER) | 慢 | ~5M |
| +PE only | 0.1742 @ iter 700 | 中等 | ~5M |
| **2D Conv (本报告)** | **0.1086 @ iter 1100** | 慢启动，后续快 | 7.9M |

> *原始模型的评估 BER 因缓冲问题未能记录，0.15 为训练 BER（tf.print）

**2D Conv 模型的 BER 比 PE-only 模型降低了 37.7%**（0.1742 → 0.1086）。

## 4. OTFS 特征分析

### 4.1 Q 矩阵可视化

在低速（3 m/s）和高速（120 m/s）条件下分别提取并可视化 Q 矩阵。

#### 定量指标

| 指标 | 低速 (3 m/s) | 高速 (120 m/s) | 变化 |
|------|-------------|---------------|------|
| Q 矩阵幅度 STD | 0.0758 | 0.0763 | +0.7% |
| 能量集中度 | 3.21× | 3.00× | **-6.5%** |
| 列 STD 均值 | 0.0753 | 0.0759 | +0.8% |
| 行 STD 均值 | 0.0748 | 0.0757 | +1.2% |

#### 关键发现

1. **能量集中度降低**：高速下 Q 矩阵的能量集中度从 3.21× 降到 3.00×（降低 6.5%），说明网络在高速时将能量更均匀地散布到 Q 矩阵的不同元素上 → **这是 OTFS 类行为的迹象**

2. **Q 矩阵差异存在但较小**：高低速 Q 矩阵的平均绝对差为 0.0321（最大 0.0884），说明网络确实根据多普勒条件调整了 Q 矩阵，但调整幅度有限

3. **幅度 STD 保持稳定**：Q 矩阵归一化确保了整体幅度均匀，STD 变化微小

### 4.2 BER 性能分析

| SNR | 低速 BER (3 m/s) | 高速 BER (120 m/s) | Δ |
|-----|------------------|---------------------|-----|
| 0 dB | 0.2703 | 0.2816 | 4% |
| 5 dB | 0.1851 | 0.2074 | 12% |
| 10 dB | 0.1367 | 0.1614 | 18% |
| 15 dB | 0.1092 | 0.1401 | 28% |
| 20 dB | 0.1011 | 0.1382 | 37% |
| 25 dB | 0.0939 | 0.1295 | 38% |

**观察**：
- 所有 SNR 下，低速 BER 优于高速 BER — 符合预期（低多普勒更容易处理）
- 高低速 BER 差距随 SNR 增大而增大（4%→38%）— 说明高速下的残余干扰在高 SNR 时成为主要瓶颈
- 25dB 时高速 BER 仍为 0.13，说明**多普勒补偿不完全**，网络未完全学到 OTFS 的理想效果

### 4.3 网络是否学到了 OTFS 特征？

| OTFS 特征 | 观察 | 判断 |
|-----------|------|------|
| **Delay-Doppler 二维处理** | Conv2D 在 delay-time 平面上同时处理 | ✅ 架构支持 |
| **高速下能量散布** | 能量集中度降低 6.5% | ✅ 有趋势，但幅度小 |
| **Q 矩阵依赖信道条件** | Q 差异均值 0.032 | ⚠️ 存在但有限 |
| **高速鲁棒性** | 25dB 时高速 BER 仍 0.13 | ❌ 多普勒补偿不足 |

**总体判断**：2D Conv 网络**开始展现出 OTFS 类特征**（高速下能量更分散），但距理想的 delay-Doppler 域完全对角化还有较大距离。

## 5. 局限性与改进方向

### 5.1 当前局限

1. **输入信息有限**：仅 3 个 OFDM 符号的 CIR 快照，无法充分解析高速下的多普勒频移
2. **2D 输入尺寸极小**：10×3 的输入对 Conv2D 来说非常小，3×3 卷积核仅需几步就覆盖全图
3. **信道估计瓶颈**：仅 1 个导频 OFDM 符号用于 LS 信道估计，时变场景下估计精度不足
4. **训练未收敛到最优**：训练在 1100 轮后开始过拟合，可能需要更好的正则化

### 5.2 改进方向

| 优先级 | 方向 | 预期效果 |
|--------|------|----------|
| 高 | 增加时间快照数（3→8+） | 提供更长的多普勒观测窗口 |
| 高 | 添加更多导频符号 | 改善时变信道估计精度 |
| 中 | 使用更大的 2D 输入（增加子载波数） | 提升 Conv2D 的感受野利用率 |
| 中 | 学习率调度（cosine decay） | 更稳定的收敛 |
| 中 | 多尺度 2D Conv（不同 dilation） | 捕获不同尺度 delay-Doppler 特征 |
| 低 | 引入显式 delay-Doppler 变换层 | 直接模拟 OTFS 的 ISFFT/SFFT |
