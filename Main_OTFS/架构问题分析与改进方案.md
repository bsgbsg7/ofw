# OTFS 网络架构问题分析与改进方案

## 当前状态

- 架构: 2D Conv (4 blocks, 3×3 kernels) → GlobalAveragePooling2D → Dense → Q matrix
- 快照数: 12 (已从 24 减小)
- 输入: CIR 2D 图像 `(batch, l_tot≈10, num_snapshots=12)` 
- Loss: 纯 BCE (PAPR 已关)
- 训练: 3 阶段, cosine decay LR

## 核心问题: 为什么网络没有自动学到 TDM/OFDM/OTFS 区分?

### 问题 1 (致命): GlobalAveragePooling2D 销毁空间信息

```
CIR → 4×Conv2D → (batch, l_tot, num_snapshots, 256)
                       ↓
              reduce_mean(axis=[1,2])  ← 对 delay 和 time 同时取平均
                       ↓
                  (batch, 256)
```

这个操作是**排列不变的 (permutation-invariant)**。三种完全不同的 CIR 模式:

```
平坦信道:     CIR = [1, 0, 0, ..., 0] × 所有快照相同
多径低速:     CIR = [0.5, 0.3, 0.2, ...] × 所有快照相同  
多径高速:     CIR = 每个快照的延迟结构在变化
```

经过 GlobalAveragePooling2D 后，输出都是 256 维向量，且这三个向量的余弦相似度极高 (~0.99+)。
网络无法从池化后的特征中区分"哪个 delay tap 活跃"和"哪个时间快照有变化"。

**类比**: 相当于把一张照片的每个像素取平均得到一个灰度值，然后让你从这个单一数值判断照片里是猫还是狗。

### 问题 2: 感受野与输入尺寸不匹配

输入尺寸 ~10×12, 4 层 3×3 Conv (same padding) 的有效感受野 ≈ 9×9。
感受野几乎覆盖整个输入！每个空间位置的神经元都"看到"了全局信息，
Conv 层退化为类似 FC 层，丧失了空间特异性。

### 问题 3: Loss 不奖励波形选择

BCE loss 的梯度信号是:"这个 Q 矩阵导致 BER 高，请调整"。
没有任何梯度信号说:"平坦信道应该用 TDM"或"高速应该用 OTFS"。

网络走阻力最小的路: 学一个对所有条件都凑合能用的通用 Q。
这个 Q 既不完全是 IDFT，也不完全是 I，而是一个中间态。

### 问题 4: 训练策略

- 3 阶段太慢，每次 OOM 中断在 ~2000-3000 迭代
- SNR 范围 [10-25]dB 偏向高 SNR，低 SNR 时信道自适应波形区分度更大
- Delay spread [10-300]ns: 10ns 对于 1MHz 带宽来说"不够平坦"

### 问题 5 (次要): Q 归一化消除差异

`Q / sqrt(trace(Q·Q^H)) * sqrt(N)` 把所有 Q 强行拉到同一 Frobenius 范数。
即使 Dense head 想输出不同的 Q，归一化也把幅度差异抹掉了。

## 改进方案

### 方案 A: 结构化池化 (最小改动)

**思路**: 不改 Conv2D 结构，只改池化方式。在对 delay 和 time 取平均之前，先分别提取统计量。

```
4×Conv2D → (batch, l_tot, num_snapshots, 256)
              ↓
    ┌─────────┼─────────┐
    │         │         │
 mean(delay) mean(time) var(time) per delay
    │         │         │
 多径特征   时间演化   Doppler特征
    │         │         │
    └─────────┼─────────┘
              ↓
       Concat → Dense → Q
```

**优点**: 
- 最小代码改动
- 保留了 delay 维和 time 维的独立信息
- 参数量基本不变

**缺点**:
- Conv 层的感受野问题未解决
- 仍依赖网络自己学会使用这些统计量

### 方案 B: 减小 Conv 深度 + 结构化池化

**思路**: 在 A 的基础上，减少 Conv2D block 数从 4→2，使感受野匹配输入尺寸。

```
2×Conv2D (感受野 5×5, 相对于 10×12 输入有空间特异性)
    ↓
结构化池化 (同方案 A)
    ↓
Dense → Q
```

**优点**:
- 解决感受野问题, 每个神经元有局部感受野
- 网络能学到"delay=3 处有能量"vs"delay=0 处有能量"的空间差异
- 参数量减半, 训练更快, 不易 OOM

**缺点**:
- 特征提取能力可能下降
- 需要验证 2 层 Conv 是否足够

### 方案 C: 多尺度池化 + 减小 Conv 深度

**思路**: B + 在多尺度上提取统计量 (不同 Conv 层的输出都做结构化池化)

```
Conv2D Block 1 → 结构化池化 1
    ↓
Conv2D Block 2 → 结构化池化 2  
    ↓
Concat(池化1, 池化2) → Dense → Q
```

**优点**:
- 多尺度特征: 浅层有细粒度空间信息, 深层有语义信息
- 类似 FPN/UNet 思想

**缺点**:
- 代码改动较大

---

## 推荐

**先试方案 B**: 减小 Conv 深度 (4→2 blocks) + 结构化池化。

理由:
1. 解决核心瓶颈 (感受野 + 池化)
2. 参数量从 9.5M → ~5M, 避免 OOM
3. 单阶段训练能完整跑完 5000 iter
4. 如果有效, 再逐步加回复杂度

---

## 验证方法

训练完成后, 在三种信道条件下提取 Q 矩阵:

| 场景 | 延迟扩展 | 速度 | 期望 Q 类型 | 验证指标 |
|------|---------|------|-----------|---------|
| 平坦 | 10ns | 3 m/s | TDM | dist(Q, I) < dist(Q, IDFT) |
| 多径低速 | 200ns | 3 m/s | OFDM | dist(Q, IDFT) < 1.0 且 < dist(Q, I) |
| 多径高速 | 200ns | 120 m/s | OTFS | dist(Q, IDFT) > 1.0 且 dist(Q, I) > 1.0 |

成功标准: 三种场景的 Q 矩阵在 `dist_to_IDFT` 指标上有显著差异 (>0.3)。
