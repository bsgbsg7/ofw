# CIR 与 Q 矩阵分析报告

## 1. CIR 的物理含义：Tap 与 Snapshot

### 什么是 Tap？

**Tap（抽头）= 一个延迟 bin，对应电磁波多走一段距离后的到达时间差。**

延迟分辨率由系统带宽决定：

$$
\text{1 个 tap 的延迟} = \frac{1}{\text{带宽}} = \frac{1}{1\ \text{MHz}} = 1\ \mu s
$$

系统参数：`FFT_SIZE=32`, `SUBCARRIER_SPACING=31.25 kHz`, 带宽 = 32 × 31.25 kHz = **1 MHz**。

因此 10 个 tap 覆盖的延迟范围是 **0 ∼ 9 µs**：

```
tap 0 → 延迟 0 µs    (直射径，最先到达)
tap 1 → 延迟 1 µs    (第一条反射径，多走约 300 米)
tap 2 → 延迟 2 µs    (第二条反射径，多走约 600 米)
...
tap 9 → 延迟 9 µs    (最远反射径)
```

### 什么是 Snapshot？

**12 个 snapshot = 在 OFDM 块持续时间内，对 CIR 做了 12 次等间隔采样。**

OFDM 块总时长 ≈ 144 个时间采样点。等间距抽取 12 个 snapshot，用于观察**信道随时间的变化**：

```
时间轴 (144+ 采样点)
├── snapshot 0  (t ≈ 0)
├── snapshot 1  (t ≈ 12)
├── snapshot 2  (t ≈ 24)
├── ...
└── snapshot 11 (t ≈ 132)
```

### CIR 矩阵结构

```
CIR = [l_tot taps × num_snapshots snapshots]

    10 行 (delay 轴) → 描述"多径结构"（频率选择性）
    12 列 (time 轴)  → 描述"信道变化速度"（多普勒/时变性）
```

## 2. 平坦信道 vs 多径信道：CIR 对比

下图来自 GRU 架构在 **3 m/s 低速**下的 CIR 可视化：

### 2.1 平坦信道 (10 ns 延迟扩展)

**CIR 热力图**：只有 tap 0 有明显能量（亮黄色），其余 tap 接近零（深色）。

**CIR 时域演化**（右下子图）：4 条主要 tap 线中，tap 0（红色）稳定在高值，其余 tap 接近零且几乎不随时间变化。

**物理含义**：
- 电磁波所有路径在 1 µs 内到达 → **频率平坦衰落**
- 12 个 snapshot 高度一致 → 信道近似**静态**（低速 3 m/s）
- 相当于一个单抽头信道：`y(t) = h · x(t) + noise`

**能量分布**：`[1.0, 0.03, 0.01, 0.01, ...]`

### 2.2 多径信道 (200 ns 延迟扩展)

**CIR 热力图**：能量分散在 tap 0∼3（多个亮色条带），呈现明显的**频率选择性**。

**CIR 时域演化**（右下子图）：多条 tap 线同时活跃，tap 0（红色）最强但有多条副径（蓝/绿/紫色线）有明显能量。12 个 snapshot 间略有波动。

**物理含义**：
- 存在 3 条以上明显反射径，跨越 ∼3 µs 到达 → **频率选择性衰落**
- 不同频率的子载波经历不同的衰落幅度
- 需要 OFDM 或 OTFS 来处理频率选择性

**能量分布**：`[0.92, 0.30, 0.10, 0.06, 0.04, ...]`

### 2.3 对比总结

| 特性 | 平坦信道 (10 ns) | 多径信道 (200 ns) |
|:---|:---|:---|
| 有效 tap 数 | 1 | 3∼4 |
| RMS 延迟扩展 | 0.08 taps (80 ns) | 0.54 taps (540 ns) |
| 频率选择性 | 无（平坦） | 有（频率选择性） |
| CIR 形状 | 单脉冲 | 指数衰减拖尾 |
| 时间变化 (3 m/s) | 几乎不变 | 基本不变 |

## 3. GRU 网络学到的 Q 矩阵

### 3.1 架构

```
CIR [batch, 10 taps, 12 snapshots]
  │
  ├─ TimePositionalEncoding (正弦位置编码注入时间信息)
  │
  ├─ Path A (Delay 轴)
  │   Complex Conv1D(64, k=32) → BN → ReLU
  │   → Complex GRU(1024)               ← 序列模型，感知 CIR 长度
  │   → 多径结构特征 [batch, l_tot, 1024]
  │
  ├─ Path B (Time 轴)
  │   Transpose → Conv1D(64, k=16)       ← 沿 delay-feature
  │   → Conv1D(64, k=3, cross-time)      ← 跨 snapshot 交互 (Doppler)
  │   → GlobalAvgPool → 广播               ← 全局时变签名
  │
  └─ Fusion: Concat → Complex Dense(1024) → Dense(1024)
       → Output: Q[32×32] + q[32]
       → Q / √trace(QQᴴ) · √N   (Frobenius 归一化)
```

### 3.2 Q 矩阵可视化

下图展示了两个信道条件下网络输出的 Q 矩阵：

| 子图 | 内容 |
|:---|:---|
| **Row 1 左** | `\|Q\|` 幅度热力图 — 越亮代表该元素幅度越大 |
| **Row 1 右** | Q 的前 8 行作为"基底函数" — 每行是一个时域波形 |
| **Row 2 左** | `\|Q − IDFT\|` — 与标准 OFDM (IDFT) 的距离 |
| **Row 2 右** | 标准 IDFT 和 Identity 矩阵作为参考 |

### 3.3 定量结果 (batch=32)

| 指标 | 平坦 3 m/s | 多径 3 m/s |
|:---|:---|:---|
| Q avg dist_I | 1.34 | 1.16 |
| Q avg dist_IDFT | 5.07 | 3.58 |
| Q 单样本 dist_IDFT 范围 | [1.38, 1.45] | [1.38, 1.45] |
| Q 成对差异 (10 样本) | 1.38 ± 0.56 | 1.27 ± 0.56 |

### 3.4 关键发现

1. **Q 单样本都接近 I 矩阵**（dist_I ≈ 1.01, dist_IDFT ≈ 1.40）— 每个 Q 本身是 TDM-like
2. **Q 平均后差异显现**（dist_IDFT: 5.07 vs 3.58）— 不同信道条件下 Q 的**相位扰动方向不同**，平均后互相抵消
3. **分化机制**：GRU 读 CIR 序列 → 输出 Q ≈ I + ε(CIR)，不同 CIR 给出不同的复相位扰动 ε
4. **对比 Conv2D 架构**：Conv2D 的 dist_IDFT 范围仅 0.03∼0.05，GRU 提升了 **100 倍以上**

## 5. 三种信道场景的 CIR → Q 映射

```
┌─────────────────────────────────────────────────────────┐
│  CIR 类型          │  物理场景      │  期望 Q   │  当前  │
├─────────────────────────────────────────────────────────┤
│  短脉冲 × 不变     │  平坦+低速     │  TDM (I)  │  ✅   │
│  长拖尾 × 不变     │  多径+低速     │  OFDM(IDFT)│  🔶   │
│  长拖尾 × 时变     │  多径+高速     │  OTFS     │  ✅   │
└─────────────────────────────────────────────────────────┘

✅ = 已实现  🔶 = 部分实现 (有分化但不接近 IDFT)
```

GRU 架构成功实现了 CIR → Q 分化，但多径低速下 Q 未靠拢 IDFT。下一步可通过辅助 loss（如 `||Q - IDFT||` 对高延迟扩展信道加权）来显式引导。
